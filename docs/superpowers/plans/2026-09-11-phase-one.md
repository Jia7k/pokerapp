# Phase 1 Implementation Plan

> **For agentic workers:** Follow test-driven implementation with independent review. Track completion below.

**Goal:** Deliver the offline Swift poker foundation requested in Phase 1.

**Architecture:** A pure Swift package with independent value models, deterministic evaluation, and math helpers. An iOS UI can import PokerCore in later phases.

**Tech Stack:** Swift 6, Swift Package Manager, XCTest. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-09-11-phase-one-design.md`

## Global Constraints

- Implement Phase 1 only.
- Support iOS 17+ and macOS 14+.
- All game logic works offline; no APIs or external dependencies.
- Distinguish exact hand completion from unknown winning equity.

## Tasks

- [x] Models and evaluator: write independent category/tiebreak/validation tests in `Tests/PokerCoreTests/HandEvaluatorTests.swift` and deck tests in `CardDeckTests.swift`; run against a placeholder evaluator to establish failures, then implement `Card.swift`, `Deck.swift`, `PokerInputError.swift`, `HandEvaluator.swift`. Public entry point: `HandEvaluator.evaluate(_ cards: [Card]) throws -> HandValue`, whose `category` and `tiebreakers: [Rank]` compare by poker rank.
- [x] Draw enumeration and math: write tests for nine flush outs, eight open-ended outs, four gutshot outs, fifteen overlapping straight/flush outs, seven flop set-to-full-house/quads outs, ten turn set outs, dead cards and board-only cards. Implement `OutsCalculator.calculate(holeCards:board:deadCards:) throws -> OutsReport`, and `PokerMath.requiredEquity(potBeforeCall:callAmount:)` / `ruleOfTwoAndFour(outs:street:)`. Establish test failures before implementation.
- [x] Verification and delivery: run `swift test`, an exhaustive release evaluator audit using `POKER_EXHAUSTIVE_TESTS=1 swift test -c release`, and an iOS simulator compile; resolve independent review findings. Write `README.md` with build instructions, an executable example matching tests, probability units, and scope limitations.
